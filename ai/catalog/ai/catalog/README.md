# Smart Catalog AI

This module is responsible for automatically generating structured
product catalogs from artisan product images and descriptions.

## Input

- Product image
- Artisan voice/text description

## Output

- Product name
- Category
- Description
- Materials
- Craft type
- Colors
- Tags
- Confidence score

## AI Pipeline

Image + Voice/Text
        ↓
Product Understanding
        ↓
Structured Catalog
        ↓
JSON Output
